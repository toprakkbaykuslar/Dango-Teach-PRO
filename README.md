# Dango Teach Pro 🎓

**Dango Teach Pro** is a lightweight utility designed to transform interactive smart boards into a clean, distraction-free digital whiteboard. By providing a pure white canvas in full-screen mode, it allows educators to use built-in or external stylus tools without the clutter of traditional OS interfaces.

---

## ✨ Features
- **Instant Whiteboard:** One-click full-screen white canvas.
- **Minimalist Design:** No menus or buttons to distract students (Clean. Stable. Dango).
- **Stylus Compatible:** Works seamlessly with smart board pens and third-party drawing software.
- **Ultra Lightweight:** Minimal CPU/RAM usage, ensuring smooth performance on older smart board hardware.
